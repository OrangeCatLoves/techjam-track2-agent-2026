3. harness/evaluate.py and harness/submit.py
   Thin wrappers over the starter versions. No reimplementation.

4. harness/convergence.py
   Implements the official rule literally:
     converged = three consecutive iterations each improving validation primary by <= 0.002, OR iteration count == 50, OR wall clock == 6 hours
   Three properties that must hold:
     - never stops voluntarily before convergence fires
     - never continues after it fires
     - a restart resumes iteration count, strike count and tried-set from disk; counters are never reset
   Q3 in docs/OPEN_QUESTIONS.md is unresolved, so implement the stricter reading and make the comparison semantics a single switchable function.

5. tests/test_contract_baseline.py
   - Split row counts exactly 1,141,112 / 124,909 / 170,588
   - baseline.py --model fm gives validation primary 0.6015 +/- 0.001
   - baseline.py --model random gives validation primary 0.4834 +/- 0.002 (looser tolerance: the published figure is a 5-seed mean, we run one seed)
   These are slow. Mark them with a pytest marker so they can be skipped during fast iteration, but they must run in CI.

6. tests/test_no_test_labels.py
   - harness.data.load()['test'] tuples have length 6
   - Attempting to read index 6 on a test tuple raises IndexError
   - The stdout filter removes the test line from a captured baseline.py run

7. tests/test_convergence.py
   Hand-built score sequences asserting correct strike counts and stop points, including the resume-after-restart case.

8. tests/test_submission.py
